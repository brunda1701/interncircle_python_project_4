
# Web Scraper for Headlines & Quotes

## Project Description
A Python-based web scraper that collects quotes, authors, and tags from Quotes to Scrape using Requests and BeautifulSoup.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- JSON

## Features
- Scrapes quotes from multiple pages.
- Extracts quote text, author names, and tags.
- Saves collected data in JSON and TXT files.
- Displays a summary of the collected data.

## Website Used
https://quotes.toscrape.com/

## How to Run
Install dependencies:

pip install requests beautifulsoup4

Run the program:

python scraper.py

## Output Files
- quotes.json
- quotes.txt

## Responsible Scraping
This project uses a practice website intended for web scraping exercises. A one-second delay is included between page requests.
